2026年10月5日現在

## 職務要約

2019年からWebエンジニアとして、PHP・Laravelを中心とする設計・実装、保守運用に従事。
要件定義、顧客との仕様調整、AWS上の実行環境構築、リリースまで幅広く担当。
現在はPM・技術支援に加え、VPoEとしてリーダー育成とエンジニア組織づくりを推進。

## 活かせる経験

- バックエンド開発：Laravel・NestJSによるAPI、業務システム、CMSの設計・実装。監査ログ、決済フロー、バッチ処理、データ移行にも対応。
- プロジェクト推進：業務ヒアリング、仕様策定・合意、進行管理、技術検証、レビューを担当。PMと実装担当の双方の立場から開発を推進。
- 運用と開発基盤：Linuxでのログ調査、障害・不具合調査、AWS EC2の環境構築、Dockerによる開発環境整備、CI/CDの導入を経験。
- 技術支援と育成：複数案件のアドバイザー・レビュアーとして参画。若手へのタスク委譲と判断のレビュー、社内学習企画を実施。

## 主な技術スキル

実務での担当範囲を記載。

- PHP・Laravel／TypeScript・NestJS：API・DB設計、実装、レビュー、指導。
- Ruby・Ruby on Rails：Webアプリケーションの機能開発・保守。
- JavaScript・React・Nuxt・Next.js：画面開発。Next.jsは調査しながらの実装を含む。
- MySQL・PostgreSQL：テーブル設計、SQL作成、アプリケーション開発での利用。
- AWS EC2・Linux・Docker：アプリケーション実行環境、開発環境の構築、ログ調査。
- GitHub Actions：簡単なワークフロー構築。Terraform・Ansible：既存設定の軽微な変更。
- Kotlin・Spring Boot：AIを活用した仕様駆動開発でのAPI実装。
